# 技术文档

## 多 Agent 协同机制

本项目基于 LangGraph 的 State Graph 架构实现多 Agent 协同。

### State 定义

```python
class StarMapState(TypedDict):
    student_input: Dict       # 用户原始输入
    profile: Dict             # Agent ① 输出
    intelligence: Dict        # Agent ② 输出
    matching: Dict            # Agent ③ 输出
    visualization: Dict       # Agent ④ 输出
    status: str               # 当前状态
    errors: List[str]         # 错误日志
```

### Agent 执行流程

```
用户输入 → ProfileAgent.analyze()
         → IntelligenceAgent.gather()
         → MatchingAgent.match()
         → Visualizer.generate_full_dashboard()
         → 输出完整报告
```

### 任务闭环（对应评审"Agent能力与任务闭环"）

每个 Agent 的输出作为下一个 Agent 的输入，形成不可断裂的任务链：

1. 画像 Agent 输出能力标签 → 情报 Agent 根据标签检索匹配方向
2. 情报 Agent 输出方向列表 → 匹配 Agent 做交叉评分和排序
3. 匹配 Agent 输出推荐 → 可视化 Agent 生成图表
4. 全程可追踪（LangSmith），任意环节出错可回溯

### 数据合规与隐私

- 学生个人信息仅在 Streamlit Session State 中存储（内存），不落盘
- 心理测评结果不持久化，每次分析后即释放
- 知识库数据来自公开来源（教育部、招聘平台公开统计），标注出处
- 不收集、不传输任何可关联到个人的敏感数据
