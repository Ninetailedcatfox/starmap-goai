## 一、背景与痛点

2026 年全国高考报名人数达 1342 万，创历史新高。然而，高考志愿填报领域存在严重的"三重信息断崖"：

1. **考生对国家战略方向一无所知**：绝大多数考生只能说出"计算机""医学""师范"几个传统方向，对于胶球（BESⅢ 确认的粒子物理突破）、南天门计划（空天一体化）、可控核聚变、量子计算等国家重大战略方向毫无概念，导致大量天赋与学生选择路径严重错配。

2. **行业信息与教育选择脱节**：家长和考生的决策依据是"哪个专业好就业"的碎片化印象，缺乏基于真实行业数据的客观判断。新能源 R&D 岗位 3 年增长 240%，但报考能源动力类专业的人数并未同步变化。

3. **现有工具只做"分数匹配"不做"人生规划"**：夸克高考、掌上高考等产品本质上是一个"分数线数据库查询系统"，没有任何产品从"你是什么人 + 世界需要什么"的双重视角出发，帮助学生做长周期职业决策。

**核心痛点**：没有一个工具能在"个人特质 × 国家战略 × 行业数据"之间做交叉匹配。

---

## 二、解决方案

星图·择途是一个**基于多智能体协同的高考志愿与未来职业导航系统**。它不回答"你考多少分去哪个学校"，而是回答 **"你是什么样的人 → 这个国家在往哪里走 → 什么路最适合你"**。

核心流程：
1. **洞察 Agent**：通过对话式引导 + 标准化心理量表，生成学生能力-兴趣双维画像
2. **情报 Agent**：从国家战略文件、行业招聘数据、学科评估中提取结构化趋势知识
3. **匹配 Agent**：基于加权多维匹配算法，输出 Top 5 推荐方向 + 避坑提示 + 隐藏选项
4. **可视化 Agent**：生成交互式"人生航线图"和"如果当初知道"路径模拟器

**与现有产品的本质区别：**

| 维度 | 夸克高考 / 掌上高考 | 星图·择途 |
|---|---|---|
| 输入 | 分数 | 分数 + 性格 + 兴趣 + 价值观 |
| 输出 | 学校列表 | 生命周期的路径建议 |
| 时效 | 只看今年 | 5-15 年长周期预判 |
| 国家战略 | 无 | 核心输入变量 |
| 交互 | 查表 | 对话式探索 + 可交互可视化 |

## 三、技术架构

```
前端层    原生 HTML + Chart.js（深色星空主题，纯静态）
后端层    Python HTTP Server（ThreadingHTTPServer，多线程）
模型层    OpenAI 兼容 API（默认 gpt-5.5，可换 DeepSeek / Qwen / Claude）
匹配逻辑  LLM 先打 RIASEC 六维分数，再据此生成方向/职业/时间轴
```

多 Agent 协同通过单次 LLM 调用内嵌四段式角色分工实现：洞察（打 RIASEC 画像）→ 情报（生成前沿方向）→ 匹配（输出职业路径）→ 可视化（生成时间轴）。一次推理产出完整 JSON，前端按 Tab 分区渲染。

## 四、数据来源与合规

| 数据类型 | 来源 | 合规措施 |
|---|---|---|
| 高校/专业信息 | 教育部阳光高考平台、学科评估公开结果 | 标注出处，定期同步 |
| 行业趋势 | Boss直聘/猎聘等平台公开统计口径 | 聚合统计，不涉及个人数据 |
| 国家战略 | 十四五/十五五规划、科技部重点研发计划公告 | 原文引用，不做二次解读歪曲 |
| 学生个人信息 | 用户主动输入 | 本地 Session 处理，不落盘不上传 |
| 心理测评 | Holland RIASEC、大五人格 | 标准化量表，不存储原始回答 |

所有学生敏感数据仅在浏览器/本地 Session 内完成处理，服务端不持久化。

---

## 五、创新点

1. **首次将"国家战略方向"作为高考志愿决策的核心变量**，把胶球、南天门计划等前沿概念翻译为学生可理解的能力-路径映射
2. **多 Agent 闭环架构**天然满足 GOAI 对"任务闭环""可观测性""Agent 协同"的评审要求
3. **"如果当初知道"路径模拟器**让决策不是一次性的，而是可探索、可回溯、可对比的
4. **全链路可开源**：Agent 框架、知识图谱构建脚本、可视化组件均可独立复用
